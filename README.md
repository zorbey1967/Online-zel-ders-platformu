# Birebir — Online özel ders platformu

Next.js ile hazırlanmış birebir online özel ders uygulaması.

## Özellikler

- Marka odaklı ana sayfa ve canlı ders akışı
- Öğretmen kataloğu (arama + ders filtresi)
- Öğretmen profili ve ders rezervasyonu
- Giriş / kayıt (demo, localStorage)
- Öğrenci paneli (rezervasyon, iptal, derse katıl)
- Öğretmen paneli ve öğretmen başvurusu
- Demo canlı ders odası

## Geliştirme

```bash
npm install
npm run dev
```

Tarayıcıda [http://localhost:3000](http://localhost:3000) adresini aç.

## Scriptler

- `npm run dev` — geliştirme sunucusu
- `npm run build` — üretim derlemesi
- `npm run start` — üretim sunucusu
- `npm run lint` — ESLint
